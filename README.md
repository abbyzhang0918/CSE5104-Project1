# CSE5104 Project 1

- **code/**: `gradient_descent_optimization.py` implements gradient descent and evaluation, `scaling_convergence_speed.py` compares raw and standardized features, and `non_linear_transformations.py` analyzes log-transformed features and compares the three optimal models.
- **results/**: `scaling_convergence.png` compares raw and standardized training losses, `nonlinear_convergence.png` adds the log-transformed model, and `optimal_models.csv` lists training and testing MSE and R² for the three optimal models.
